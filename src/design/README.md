# Desain final

Buka `sisarasa.figcraft` di FigCraft 0.15.0. Ada 53 layar/state pembeli dan mitra dalam tiga halaman: fondasi, pembeli/akun dan mitra. Layar/pengaturan server telah dikeluarkan dari desain pengguna. Form lokasi merchant memiliki koordinat yang disembunyikan pada desain utama; pada aplikasi, pengeditan manual berada di panel opsional.

File memakai teks, vektor, auto layout, instance/variant, token warna dan tautan prototype yang bisa diedit. Font Lato dan Liberation Serif tersedia di `../android-app/assets/fonts/`, beserta lisensinya. `screens.json` berisi inventaris layar. Form prototype memakai contoh tetap; aplikasi Flutter memakai controller/API nyata. Pembayaran/refund/pencairan tetap simulasi.

`../docs/assets/app-overview.png` adalah screenshot dari implementasi Flutter terbaru. Gunakan file native untuk mengedit desain, bukan gambar preview.
